Al Zia Online Quran Academy - React (Vite) frontend

1. Node.js install karein (https://nodejs.org)
2. Is folder mein terminal kholein
3. npm install
4. npm run dev   (browser mein http://localhost:5173 khulega)
5. npm run build (live karne ke liye dist folder banta hai)

Text:   src/App.jsx ke shuru ki lists
Styles: src/index.css
